# Traffic Bridge Server Panel

این مخزن نسخهٔ پایهٔ پنل سرور Traffic Bridge برای استقرار روی
[Orbit / Flux](https://orbit.runonflux.com) است.

## امکانات نسخهٔ فعلی

- صفحهٔ ورود مستقل با رمز پنل
- نشست امن پنل با کوکی امضاشده و زمان انقضای ۱۲ساعته
- پنل دوگزینه‌ای:
  1. ورود با حساب شاد در `https://web.shad.ir`
  2. فعال‌سازی و غیرفعال‌سازی ارتباط
- ذخیرهٔ وضعیت پنل در فایل محلی با دسترسی محدود
- اجرای دستور واقعی ارتباط فقط از متغیرهای محیطی سرور
- وضعیت قرمز/سبز و گزارش خطای صریح
- Dockerfile بدون وابستگی خارجی
- ظاهر هم‌راستا با برنامهٔ موبایل HooshNet، شامل آیکون مشترک، دسته‌بندی پنل و حالت روشن/تیره
- اسکریپت تم جدا از HTML برای سازگاری با Content-Security-Policy

## نکتهٔ مهم دربارهٔ نشست شاد

پنل عمداً رمز عبور، کوکی یا توکن شاد را از طریق سرور دریافت نمی‌کند. صفحهٔ شاد
داخل iframe نمایش داده می‌شود و یک مسیر جایگزین برای باز کردن آن در تب جدید دارد؛
برخی نسخه‌های `web.shad.ir` ممکن است به‌دلیل سیاست‌های امنیتی مرورگر اجازهٔ
نمایش داخل iframe را ندهند.

دکمهٔ «ورود انجام شد» فقط وضعیت آماده‌بودن نشست مرورگر را در پنل ثبت می‌کند.
این به‌تنهایی یک توکن قابل استفاده برای سرویس شبکه تولید نمی‌کند. برای برقراری
واقعی ارتباط باید روش رسمی و مجاز احراز هویت شاد یا سرویس واسط مورد تأیید آن
مشخص شود. تا آن زمان سرور اجازه نمی‌دهد وضعیت ارتباط به‌صورت ساختگی سبز شود.

## متغیرهای اجباری Orbit

```text
PANEL_PASSWORD=<رمز پنل؛ فقط در Secrets/Environment تنظیم شود>
SESSION_SECRET=<رشتهٔ تصادفی حداقل ۳۲ کاراکتری>
```

متغیرهای اختیاری:

```text
PORT=2053
STATE_FILE=/app/data/state.json
SHAD_URL=https://web.shad.ir
COOKIE_SECURE=true
BRIDGE_ENABLE_COMMAND=/app/scripts/activate-connection.sh
BRIDGE_DISABLE_COMMAND=/app/scripts/deactivate-connection.sh
```

`COOKIE_SECURE=true` را برای استقرار پشت HTTPS فعال کنید. برای اجرای محلی روی
HTTP می‌توان آن را موقتاً `false` گذاشت.

## فعال‌سازی شبکه

فایل‌های `scripts/activate-connection.sh` و
`scripts/deactivate-connection.sh` عمداً با خطا تمام می‌شوند و ارتباط واقعی را
جعل نمی‌کنند. محتوای آن‌ها را فقط در محیط سرور با اسکریپت server-owned واقعی
جایگزین کنید؛ سپس آن اسکریپت باید:

1. فایل تنظیمات شبکه را از مسیر امن دریافت کند؛
2. اعتبارسنجی و اعمال تنظیمات را انجام دهد؛
3. فقط در صورت موفقیت واقعی با کد خروجی صفر تمام شود؛
4. در خطا کد خروجی غیرصفر بدهد.

سپس مسیر آن را در `BRIDGE_ENABLE_COMMAND` و `BRIDGE_DISABLE_COMMAND` قرار دهید.
دستورها از ورودی کاربر ساخته نمی‌شوند و فقط از تنظیمات محیط سرور خوانده می‌شوند.

## تنظیم Orbit / Flux

1. این مخزن را به‌عنوان Source پروژه انتخاب کنید.
2. پورت عمومی را روی `2053` قرار دهید.
3. متغیرهای اجباری را در بخش Secrets/Environment ثبت کنید.
4. دیسک پایدار برای `/app/data` فعال کنید تا وضعیت پنل بین restartها حفظ شود.
5. Build/Deploy را اجرا کنید.
6. ابتدا ورود پنل را تست کنید، سپس ورود شاد، و در پایان دستور واقعی ارتباط را
   روی یک سرور آزمایشی بررسی کنید.

## وضعیت توسعه

این commit پنل سرور و قرارداد اجرای دستور شبکه را آماده می‌کند. اتصال واقعی
به شبکه و قالب نهایی فایل تنظیمات هنوز باید بر اساس سرویس/پروتکل واقعی سرور
تکمیل شود؛ بدون آن، دکمهٔ فعال‌سازی عمداً خطای تنظیم‌نشدن دستور را گزارش می‌کند.
